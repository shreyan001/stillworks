# HANDOFF — checkpoint for model or session swap

Write this before switching models, when context gets long, or at a natural pause. The next lead reads it first.

```
Checkpoint:          date time IST · outgoing model/session
Goal:                the current overall goal, in shreyan's words
Verified state:      facts with evidence (link to STATUS.md lines)
Approved decisions:  IDs from DECISION_LOG.md
Proposals pending:   not yet approved
Open questions for shreyan:  (the next ONE to ask first)
Unknowns / research in flight: work-order IDs, owners, status
Contradictions open: …
Artifacts:           files created/changed this session (paths)
Next action:         one concrete step
Don't do:            anything shreyan ruled out
```
