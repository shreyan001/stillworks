# RESEARCH_PROTOCOL

## Every fact needs
- Source URL (official docs, repo, prize page preferred)
- Checked time (IST) and the page's own "last updated" date if shown
- Label: verified (read the source this session) / reported (from another agent or doc) / assumption

## Verification
- Prefer primary sources. Secondary sources (blogs, forums, AI answers) are leads, not facts.
- Check versions: a doc, template or package can be stale (e.g. a README with an old chain ID). Note the date.
- If two sources disagree, record both, the dates, and which is newer/more official. Don't silently pick one.

## Scope and stop criteria
- Each research task has one question, a time cap, and a done-when.
- Stop when: the question is answered with a primary source; or the time cap is hit; or the answer needs access only shreyan has (login, account, booth). Report what's unknown and who could answer.
- Don't widen scope mid-task. New questions go to the lead as proposals.

## Contradictions log
Keep a section in STATUS.md or `CONTRADICTIONS.md`:
`claim · source A (date) · source B (date) · impact · resolution or "open"`

## Never
- Transactions, purchases, sign-ups, or posting during research without approval.
- Presenting a guess as a fact.
